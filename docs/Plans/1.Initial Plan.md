# Smartcar MG4 X Range 2026 - Node.js Integration App

A full-stack Node.js application integrating with the Smartcar API v3, covering all available endpoints with an Express backend, Angular frontend, CLI tool, SQLite storage, Smartcar Connect OAuth flow, and webhook receiver with ngrok support.

---

## Architecture Overview

```
smartcar/
  backend/             # Express.js REST server (TypeScript)
    src/
      config/          # Environment, constants, database setup
      db/              # SQLite schema, migrations, repository layer
      auth/            # OAuth token management (client credentials + Connect flow)
      api/             # Smartcar API client (direct HTTP, no deprecated SDK)
        client.ts      # Base HTTP client with token refresh
        connections.ts # Connections endpoints
        vehicles.ts    # Vehicle data & signals endpoints
        commands.ts    # Vehicle commands (charge, lock, nav, schedules)
        webhooks.ts    # Webhook & subscription management
        compatibility.ts # Compatibility API (public, no auth)
        management.ts  # Management API (applications, secrets)
      routes/          # Express route handlers
        auth.routes.ts
        connections.routes.ts
        vehicles.routes.ts
        commands.routes.ts
        webhooks.routes.ts
        compatibility.routes.ts
        management.routes.ts
      middleware/       # Auth, error handling, webhook verification
      utils/           # Helpers, logger
      app.ts           # Express app setup
      server.ts        # Entry point
    package.json
    tsconfig.json
    .env.example
  frontend/            # Angular app
    src/app/
      core/            # Services, interceptors, guards
      shared/          # Common components, pipes
      features/
        dashboard/     # Main vehicle dashboard
        connect/       # Smartcar Connect flow UI
        signals/       # Vehicle signals viewer
        commands/      # Vehicle command controls
        webhooks/      # Webhook event log viewer
        compatibility/ # Vehicle compatibility checker
        settings/      # App settings, connection management
  cli/                 # CLI tool (TypeScript)
    src/
      commands/        # Individual CLI commands
      utils/           # Shared CLI utilities
    package.json
  docs/                # Generated documentation
```

## Technology Stack

- **Runtime**: Node.js 20+ with TypeScript
- **Backend**: Express.js 4.x (direct HTTP calls to Smartcar v3 API, no deprecated SDK)
- **Frontend**: Angular 17+ (standalone components, Angular Material)
- **CLI**: Commander.js + Inquirer.js
- **Database**: SQLite via better-sqlite3
- **HTTP Client**: Built-in fetch (Node 20+)
- **Webhook tunneling**: ngrok (dev mode)
- **Auth**: OAuth 2.0 Client Credentials flow + Smartcar Connect

### Sub-Plan 2: Authentication & Token Management

**Goal**: Implement OAuth 2.0 client credentials flow, token caching with auto-refresh, and the Smartcar Connect vehicle authorization flow.

**Context needed**: Sub-plan 1 is complete. Backend project exists with Express skeleton and SQLite.

**Steps**:

1. **Implement Smartcar auth client**
   - `backend/src/auth/token-manager.ts`:
     - `getAccessToken()` - returns cached token or fetches new one
     - `fetchNewToken()` - POST to `https://iam.smartcar.com/oauth2/token` with client_credentials
     - Token cached in SQLite with expiry tracking (1hr validity, refresh at 50min)
     - Handles concurrent requests (single in-flight token refresh)

2. **Implement base HTTP client**
   - `backend/src/api/client.ts`:
     - `SmartcarClient` class wrapping Node.js fetch
     - Auto-attaches `Authorization: Bearer {token}` header
     - Auto-attaches `sc-user-id` header when provided
     - Handles rate limiting (429), retries with exponential backoff
     - Parses JSON:API error responses into typed errors
     - Supports both Vehicle API and Management API base URLs

3. **Implement Smartcar Connect flow**
   - `backend/src/auth/connect.ts`:
     - `buildConnectUrl(options)` - constructs the Connect URL with parameters:
       - `application_id`, `redirect_uri`, `response_type` (code or none), `mode` (simulated/live)
       - Optional: `scope`, `state`, `make`, `single_select`, `single_select_vin`, `external_id`, `flags`
     - `handleConnectCallback(queryParams)` - processes the redirect response
       - Extracts `user_id`, stores in SQLite
       - Handles error responses (access_denied, vehicle_incompatible, etc.)

4. **Create auth routes**
   - `backend/src/routes/auth.routes.ts`:
     - `GET /auth/connect` - redirects user to Smartcar Connect
     - `GET /auth/callback` - handles Connect redirect, stores user_id
     - `GET /auth/status` - returns current auth status (has token, has users)
     - `POST /auth/token` - manually trigger token refresh (admin utility)

5. **Create auth middleware**
   - `backend/src/middleware/auth.middleware.ts`:
     - Ensures valid access token exists before proxying to Smartcar
     - Extracts and validates `sc-user-id` from request headers or query params

6. **Verify**: 
   - Test token acquisition with valid credentials
   - Test Connect URL generation
   - Test Connect callback handling (using simulated mode)

**Files created**: ~8 files
**Estimated tokens**: Medium

## Key Design Decisions

1. **Direct HTTP, no SDK**: Smartcar's Node.js SDK is in maintenance mode (security patches only until Dec 2026). We use direct `fetch()` calls to the v3 API for longevity.

2. **TypeScript throughout**: Type safety for all API request/response types, signal codes, and command parameters.

3. **SQLite for persistence**: Lightweight, zero-configuration, perfect for single-user car owner app. Stores tokens, connections, signal history, and webhook events.

4. **Proxy architecture**: Angular frontend calls our Express backend, which proxies to Smartcar. This keeps credentials server-side and allows us to cache, log, and enhance responses.

5. **Simulated mode first**: All development and testing uses Smartcar's simulated mode. Switch to live mode via `.env` for real car interaction.

6. **MG4-focused but universal**: While optimized for MG4 X Range 2026 (BEV), the app supports any Smartcar-compatible vehicle. MG-specific features are highlighted in the compatibility and dashboard sections.
